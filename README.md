\# Веб-приложение "Интеллектуальная система планирования доходов банка"



Краткое описание:  

Проект представляет собой веб-приложение, состоящее из трёх сервисов:

\- \*\*Backend\*\* (Java + Spring Boot) – основная серверная логика, REST API и WebSocket.

\- \*\*Frontend\*\* (React + TypeScript) – пользовательский интерфейс.

\- \*\*Python-сервис\*\* – дополнительный микросервис (обработка данных, интеграции и т.п.).



Все компоненты взаимодействуют через HTTP и WebSocket, база данных – H2.

\## Установка и запуск



\### 1. Backend (Java / Spring Boot)



Перейдите в папку:



```bash

cd ./backend

```



\*\*Настройка JDK:\*\*  

В файле `backend/gradle.properties` укажите путь к JDK 17.0.19, например:

```properties

org.gradle.java.home=/путь/к/jdk-17.0.19

```

Если переменная `JAVA\_HOME` уже указывает на нужную версию, можно оставить файл пустым.



\*\*Запуск:\*\*



```bash

./gradlew bootRun

```



После запуска backend доступен по адресу:  

\*\*http://localhost:5000\*\*



\---



\### 2. Frontend (React + TypeScript)



Перейдите в папку:



```bash

cd ./frontend

```



Установите зависимости:



```bash

npm install

```



Запустите режим разработки:



```bash

npm run dev

```



Приложение будет доступно по адресу:  

\*\*http://localhost:8080\*\* (порт может отличаться – смотрите вывод консоли).



\---



\### 3. Python-сервис



Перейдите в папку:



```bash

cd ./python-service

```



Установите зависимости (если есть `requirements.txt`):



```bash

pip install -r requirements.txt

```



Запустите сервис (например, для Flask):



```bash

python app.py

```



Сервис обычно поднимается на порту, указанном в конфигурации (например, 5001).  

Подробнее – в `docs/architecture.pdf`.
